动效与音效（脚本里全部用 TweenService 实现，共用一套缓动曲线）：
· 开机：品牌区依次落下 → 终端逐行打印并打上 OK → 进度条带亮点推进 → 整屏淡出
· 语言选择：图标 / 品牌 / 两张卡依次落下；悬停时卡片抬起 4px、描边亮起、箭头右推
· 主界面：窗口从 0.9 弹回原尺寸，顶栏 → 侧栏 → 内容依次入场；切页时内容整页轻浮 + 侧栏指示条滑过去
· 滑块：旋钮拖动时放大 1.34 倍、描边加粗；按钮：点击从落点扩散一圈涟漪
· 提示音 discord-notification.mp3：右下角每次弹提示都会响（进场欢迎 / 复制邮箱 / 开关飞行 / 切语言…）
· 关闭：error-soundss.mp3 + 窗口抖四下再缩下去 → 全屏告别层「期待下次注入」→ 约 2 秒后自行销毁
