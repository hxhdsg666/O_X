# O_X HUB

Roblox 执行器脚本，通过 `loadstring` + `HttpGet` 分发。

## 脚本列表

| 文件 | 说明 |
| --- | --- |
| `O_X_HUB.lua` | 语言选择 + 软件式主界面（主页 / 服务器 / 通用 / 飞行 / 设置）+ 开机动画 |
| `preview_v180.html` | 全部界面的 1:1 视觉预览（浏览器打开） |

## 用法

执行器里粘贴执行：

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/hxhdsg666/O_X/refs/heads/main/O_X_HUB.lua"))()
```

改完脚本发现还是旧效果，加时间戳破缓存：

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/hxhdsg666/O_X/refs/heads/main/O_X_HUB.lua?t=" .. os.time()))()
```

## 功能

### 语言选择（注入后的第一屏）
执行脚本后先弹出一屏语言选择：中间是图标 + `O_X HUB`，下面两个入口带国旗。

| 入口 | 之后 |
| --- | --- |
| 🇺🇸 English | 加载动画 + 主界面**全英文** |
| 🇨🇳 中文 | 加载动画 + 主界面全中文 |

规则：**除了 `O_X HUB` 这个名字本身，英文模式下界面里不会出现任何汉字**（中文模式同理不会混英文）。文案全部走一张语言表，漏翻会直接显示 key 方便发现。

### 开机动画
选完语言才播。做成一段**终端启动序列**：品牌区依次落下，右边终端逐行打印 `> 初始化运行环境... OK`，
底部进度条带亮点推进，一条细光带扫过全屏，最后整屏淡出。阶段文案跟随语言。

### 界面风格
一份**锁死的设计令牌**，不在业务代码里现编颜色 / 圆角 / 缓动：

| 令牌 | 值 |
| --- | --- |
| 强调色 | 只有一支：`#E83448`（红），渐变另一端 `#FF7A2E` 只用在渐变里 |
| 语义色 | 绿 `#34C77B` 只表示"正在运行"，红 / 琥珀只表示失败 / 警告 |
| 圆角 | 窗口 16 / 卡片 12 / 控件 10 / 胶囊 999 |
| 缓动 | `pop` Back / `out` Quint / `soft` Quad / `fast` Quad / `gone` Quad In |
| 字体 | GothamBold 标题、GothamMedium 正文、**Code 等宽**跑数值和终端行 |

动效原则是"每个动画都要有理由"，不是为动而动：

- **进场**：品牌区 / 卡片 / 侧栏内容都从下方 8~12px 依次落下淡入（stagger）
- **悬停**：卡片抬起 2~4px + 描边亮起 + 箭头右推；按钮背景 / 描边 / 文字一起过渡
- **点击**：从落点扩散一圈涟漪（`MouseButton1Down` 拿坐标）
- **滑块**：旋钮拖动时放大 1.34 倍、描边加粗，松手回弹
- **切页**：内容整页轻浮 + 侧栏那条**滑动指示条**滑到当前项
- **飞行中**：飞行窗口顶栏一条细线开始呼吸（表达真实状态，不是装饰）
- **关闭**：窗口抖四下再缩下去

### 主窗口
做成软件的样子，**顶栏、飞行窗口、悬浮图标都能拖动**：

| 按钮 | 行为 |
| --- | --- |
| `－` | 缩成一个圆形悬浮图标，点图标重新展开 |
| `✕` | **结束整个脚本**：停飞行、撤伤害保护、断开所有连接、还原改过的属性、销毁界面 |

`✕` 是真的关掉，不是隐藏——关掉之后按 `F` 也没反应了。想再用就重新执行一次 loadstring。
重复执行不会叠出两套界面：新的一份会先把旧的卸干净。

悬浮图标也能拖（位移超过 6px 才算拖动，轻轻点一下还是打开窗口）。

左侧是功能列表：

- **主页** — 欢迎页 + 数值一览 + 飞行 / 通用卡片
- **服务器** — 列出可用的服务器脚本，点卡片打开它专属的面板（见下）
- **通用** — 移动速度 / 跳跃高度 / 重力，拖滑块立即生效，复活后自动重新应用；还有**防挂机**（见下）
- **飞行** — 点一下打开独立的飞行窗口
- **设置** — 联系作者 + 语言切换（和主页一样是**页面**，不会新开窗口）

### 防挂机（通用页）
Roblox 挂着不动 20 分钟会把你踢出去。开启后，游戏一触发 `LocalPlayer.Idled`
就用 `VirtualUser` 假点一下鼠标 —— 闲置计时器被重置，人不用动也不会被踢。

关掉就恢复原样（连接断开，不再干预）。

### 设置
- **联系作者**：显示 `oxhub@atomicmail.io`，点整张卡片复制到剪贴板，右下角弹提示
- **音效**：总开关。关掉之后一点声音都没有；重新打开时会响一声作为反馈
  - 各家执行器的剪贴板函数**名字和位置都不一样**，所以是层层兜底地找：
    ① 脚本加载时用**裸全局引用**抓一遍（`setclipboard` / `toclipboard` / `set_clipboard` / `setrbxclipboard`）
    ② `_G` ③ `getgenv()` ④ 再扫一遍环境里所有名字带 `clip` 的可调用项
    —— 有些执行器给脚本的是沙箱环境，那里的 `_G` 是空表，只有裸全局引用能拿到
  - 也兼容被包成 table / userdata（带 `__call`）的情况
  - 真的一个都没有时，会在控制台打印"环境里带 clip 的名字"方便排查，界面上明确提示手动复制
- **语言**：两个按钮（当前语言高亮）。点另一个语言 → 提示「已切换为 xx，正在重启...」→ 0.45 秒后**把旧界面整体卸载、用新语言重新建一遍**（等价于重启，但不用重新注入，也不会闪一下语言选择页）

### 音效
两个 mp3 直接内联进脚本（base64），运行时落盘成 `rbxasset://` 再用 `Sound.SoundId` 播：

| 文件 | 用在哪 |
| --- | --- |
| `discord-notification.mp3` | 右下角每次弹提示（进场欢迎 / 复制邮箱 / 开关飞行 / 切语言 / 恢复默认…） |
| `error-soundss.mp3` | 点主窗口 ✕ 结束脚本时，配关闭动画 + 全屏告别层「期待下次注入」 |

拿不到文件 API 或 `Sound` 播不出来时**只是没声音**，不会报错、不会挡住界面。设置页有总开关。

### 提示条
改成**右下角一叠 toast**：从右侧滑进来，新的在下、旧的往上顶；底部有一条倒计时细线，
3.4 秒后自己滑出去。颜色即语义（绿 = 成功，红 = 失败 / 普通）。

### 关闭动画
点主窗口 ✕ → 播 `error-soundss.mp3` → 窗口左右抖四下再缩下去 → 弹一层全屏告别：
图标 + `O_X HUB` + 「正在关闭...」+ **期待下次注入** + 一条耗尽式进度线 → 约 2 秒后自行销毁。
（重启走的是另一条路：`unloadAll(true)`，不放动画也不出声。）

界面的每一处运行时状态（主窗口、飞行窗口、悬浮图标、提示条 GUI、所有事件连接）都装在 `boot(lang)` 里，所以"重启"就是 `unloadAll` + 再跑一次 `boot`。语言包和图标资源缓存在 `boot` 外面，重启时不用重新落盘。

### 服务器脚本
「服务器」是主页旁边的一个 page，右边列出可用的服务器。目前有 **2 个**：

| 服务器 | Place ID | 面板 |
| --- | --- | --- |
| 自然灾害模拟器 | `189707` | 传送 / 农场 |
| Notoriety | `21532277` | 潜入 / 强攻 |

点卡片会打开一个**独立窗口**（和飞行窗口一个套路：顶栏可拖、`－` 收成悬浮胶囊、`✕` 关掉、
打开时播一段开场动画）。窗口左边是分区，右边是内容。

**不在对应服务器里会被拦住**
点卡片时会先比对 `game.PlaceId`：

- 对得上 → 正常打开面板
- 对不上 → **不给用**，响一声 `bruh.mp3`，同时弹一个模态窗
  （标题「未在对应服务器内」，说明这个脚本只能在哪个服务器用，并显示当前 Place ID）

模态窗里还有一颗 **「加入对应服务器」** 按钮：

1. 先尽量把重新执行脚本的代码排进队列（`queueonteleport` / `queue_on_teleport` /
   `syn.queue_on_teleport`，按顺序找），这样落地之后脚本会**自动再跑一次**
2. 再调 `TeleportService:Teleport(placeId, LocalPlayer)` 跳过去
3. 窗子自动关掉

> 拿不到任何 queue 函数时**照样传送**，但会如实提示一句
> 「这个执行器不支持传送后自动执行，落地后请手动再注入一次」。
>
> 右上角 **✕ 关闭**。

> 这种检查只防误用，不防有人在正确的游戏里开脚本 —— 它拦的是"跑错地方"。
> 拦截窗是模态的，盖在所有界面之上，关掉脚本时也会一起收掉。

**传送**
两个地点可选，选中一个再点下面的「传送」按钮：

| 地点 | 坐标 |
| --- | --- |
| 出生点 | `(-270.72, 195.99, 360.30)` |
| 游戏场地 | `(-105.43, 48.89, 6.61)` |

> 这两个坐标是社区脚本里通用的固定点。出生点是大厅，灾害打不到；游戏场地是每局开始
> 所有人被送过去的那个岛。

**农场**
一个「自动获胜」开关。开启后：

1. 立刻把你送回出生点
2. 挂一个 `Heartbeat` 一直盯着，**离出生点超过 34 studs 就立刻拉回来** ——
   游戏开局把你传去场地也会被顶掉，等于免疫游戏内的传送
3. 顶栏和开关旁边亮一个「运行中」

关掉开关就停。**关掉服务器窗口不会停**（不然挂机就白挂了）；
但点主窗口 `✕` 结束整个脚本时会一起停掉。

### 服务器脚本：Notoriety（place `21532277`）

**Notoriety** 就是那款 Payday 风格的 Roblox 劫案游戏（主游戏 = 大厅，地图是同一 universe 下的其它 place）。
脚本里用到的场景结构：

| 东西 | 位置 |
| --- | --- |
| 敌人（警卫 / 警察） | `Workspace.Police` |
| 平民 | `Workspace.Citizens` |
| 战利品 | `Workspace.BigLoot`（老图是 `Workspace.Lootables`） |
| 撤离点 | `Workspace.BagSecuredArea.FloorPart` |
| 远程 | `ReplicatedStorage.RS_Package.Remotes`（`StartInteraction` / `CompleteInteraction` / `ThrowBag`） |

> 这些名字来自社区里几个开源 Notoriety 脚本（DarkHub、rblxploit、JBR/RealNotorietyLib、notoriety-autowin），
> 不是我猜的。游戏大更新改了文件夹名的话，脚本里都在 `pdChild(...)` / `pdRemote(name)` 里，改一处就行。

面板分两种形态：

| 你在哪 | 面板长什么样 |
| --- | --- |
| 主游戏（`game.PlaceId == 21532277`） | 只说「正在更新 / 主游戏暂无脚本」，左侧两个分区不出现 |
| 任意劫案地图（同一个 universe 的其它 place） | 右上角显示「地图：珠宝店」，左侧出现 `潜入 / 强攻` |

判定用 `game.GameId == 16680835`（同一个 universe 的所有 place 共用 `GameId`），所以在主游戏里注入、
进地图之后照样能开面板。地图名走 `MarketplaceService:GetProductInfo`，拿不到就查 `PD.Maps`，
再拿不到才显示 `#placeId`。

**潜入**

| 开关 / 滑块 | 说明 |
| --- | --- |
| 自动完成 | 主流程：找战利品 → 过去 → 交互（`StartInteraction` / 按住 / `CompleteInteraction`）→ 瞬移到撤离点 → `ThrowBag` → 下一件，循环到没得拿 |
| 自动交互 | 只在范围内顺手按附近所有 `ProximityPrompt` / `ClickDetector`（不走路线） |
| 瞬移 | 开 = 直接 `CFrame` 过去；关 = 按下面的速度跑过去（参考脚本是 75 studs/s 的 tween，速度检测更友好） |
| 目标高亮 | 给战利品 / 交互点挂白字名牌，隔墙可见 |
| 交互范围 / 高亮范围 / 移动速度 | 5~80 / 20~600 / 20~300 |

- 面板右上角有实时进度「自动完成 · 已拿走 3 件」，每次拿一件还会弹一条提示条 —— 不会出现"点了没反应"
- 同一件战利品只处理一次（弱键表记着），换图后自动清空
- 交互最多重试 3 次：成功的话 prompt 会被销毁或 `Enabled = false`，那就提前结束
- 只做「拿东西 + 送包」，不会自动点 Ready / 自动回大厅（那属于挂机刷，要的话说一声）

**强攻**

| 开关 / 滑块 | 说明 |
| --- | --- |
| NPC 自瞄 | 视角转到敌人身上 **同时**用执行器的鼠标函数把准星压到头上（`mousemoveabs` / `mousemoverel`）→ 子弹跟着准星走，跟手动瞄准一个路子，不是改射线 |
| 自动开火 | `Tool:Activate()` → `mouse1click` → `VirtualUser`，依次降级 |
| 只瞄敌人 | **默认开**。只锁 `Workspace.Police` 里的人；平民、队友、AI 补位的都不用管。玩家角色（`Players:GetPlayerFromCharacter`）永远不瞄 |
| 锁头 | 默认开；关掉打身体 |
| 隔墙也瞄 | 默认关 = 只瞄射线打得通的 |
| 全场透视 | 所有人 + 战利品都挂名字，按类型分色：**红 = 敌人，琥珀 = 平民，绿 = 队友，白 = 战利品**；用 `BillboardGui`（`AlwaysOnTop`），没有 `Highlight` 那种 31 个的数量上限 |
| 优先目标 | 准星最近 / 距离最近 / 血量最低 |
| 视场角 / 自瞄范围 | 10°~360° / 20~1000（透视范围写死 600 studs） |

- NPC 每 0.4 秒扫一次 `workspace`（`Humanoid` + `Health > 0`），自瞄和透视都吃这份缓存
- 鼠标被锁在屏幕中心的游戏（`MouseBehavior.LockCenter`）只转视角、不动鼠标，免得每帧抖
- **✕ 只关窗口**，两个分区的状态继续跑；主窗口 `✕` 结束脚本时才全停，并把挂在场景里的透视清干净

### 飞行（独立窗口）
独立小窗，顶栏可拖动：

| 按钮 | 行为 |
| --- | --- |
| `－` | 收成侧边胶囊，点胶囊重新展开（飞行状态不变） |
| `✕` | **只结束飞行**：走落地保护停下来 + 收起窗口，不留胶囊 |

关掉之后要再开，去主页的飞行卡片或左侧「飞行」导航。首次打开会播一段 `O_X 飞行` 的启动动画。

| 操作 | 说明 |
| --- | --- |
| `F` / 点按钮 | 开关飞行 |
| 官方摇杆 / `W A S D` | 控制飞行方向 |
| 滑动屏幕 | 调整朝向；抬头 + 前进 = 上升 |
| `空格` | 上升 |
| `左Ctrl` / `左Shift` | 下降 |
| 速度滑块 | 0.01 ~ 3000（对数刻度） |

**没有额外的升降按钮**——开启后角色直接进入飞行状态，用游戏自带的摇杆和键盘控制。

松手时速度归零 = 原地悬停，不会被重力拽下去。

### 伤害保护（有掉落伤害 / 撞击伤害的服务器）
像自然灾害模拟器这类服务器，伤害判定基本都在**服务端**：要么监听 `Humanoid.StateChanged` 的 **Freefall → Landed** 算摔落高度，要么直接读同步过去的**角色速度**。所以在这些服里"关飞行 = 摔死"，**飞太快撞到东西也会掉血**。

所以这里做了三层：

**① 速度回零（主要手段）**
每个 `Heartbeat` 末尾把 `HumanoidRootPart.AssemblyLinearVelocity` 存下来清零，下一帧 `RenderStepped` 开头再还原。中间那一小段正好是网络同步窗口——**服务端读到的角色速度恒为 0**，摔伤判不到，高速撞到东西也判不到。角色的实际移动完全不受影响（还原发生在物理步之前）。

- 飞行期间一直生效
- 关飞行后会一直撑到角色落地，再多撑 0.8 秒才停，把落地那一瞬间也盖住
- 角色消失 / 复活时立刻撤掉

**② 状态屏蔽**
飞行和贴地放手期间关掉 `Freefall` / `Landed` / `FallingDown` 三个状态，不给状态判定任何机会。只在确认贴地时才屏蔽，0.5 秒后自动恢复——否则玩家主动从高空跳下去会卡在空中。

**③ 落地缓降**
关飞行时不马上放手，先挂一个缓降速度往下送——**离地越远降得越快，越贴近降得越慢**（最高 110，贴地前降到个位数）。降到脚底刚好接触地面、速度彻底归零，还额外等 0.12 秒让物理稳定，最后才放开 `PlatformStand`。放手时角色是**站在地上**的，状态机不会产生 Freefall → Landed 的转换。

已经在低空时关飞行会直接放手，不会多绕一圈。缓降途中再按一次 F 可以随时打断重新起飞。

飞行窗口里有两个开关：「**伤害保护**」（①② 的总开关）和「**落地缓降**」（③）。都不喜欢就都关掉。

⚠️ **写出来的文件名带内容哈希**（`oxhub_<key>_<hash>.<ext>`）。用固定文件名的话，换图之后执行器里残留的旧文件会让"已存在就跳过写入"直接跳过，`getcustomasset` 也按文件名缓存 —— 结果就是**换了图但界面还是旧的**。带哈希之后图一变文件名就变，从根上绕开缓存；启动时还会顺手清掉同一个 key 的历史遗留文件。

如果你之前跑过老版本、换了图还是不生效，删掉执行器工作目录里的 `oxhub_icon.jpg` 再执行一次就好（新版本会自动删）。

> 哈希格式化踩过的坑：`string.format("%x", h)` 在部分运行时（数值走双精度、位运算只有 32 位的那种）遇到 **大于 2³¹ 的哈希值**会直接报 `number has no integer representation`。所以这里改成手写十六进制，只依赖 `math.floor` 和除法。

> 取执行器注入的函数时，**先裸全局引用，再 `_G`，再 `getgenv()`**。
> 有些执行器给脚本的是沙箱环境，那里的 `_G` 是一张全新的空表，
> 只有裸全局引用（顺着 `__index` 回落到真正的环境）才拿得到函数。

## 注意

- 地址必须是 `raw.githubusercontent.com`，用 `github.com/.../blob/...` 会拿到 HTML，`loadstring` 会报语法错误。
- 仓库必须**公开**，私有仓库的 raw 地址需要鉴权，执行器取不到。
- 文件名建议保持纯英文，部分执行器的 `HttpGet` 对非 ASCII 路径处理不一致。
- 「重力」改的是 `workspace.Gravity`，会影响整个服务器的物理表现，慎调。
- **改界面文案时不要再往代码里直接写中文/英文字面量**，一律加进 `LOCALES` 再用 `L("key")` 取。离线测试里有一条断言会遍历整个主界面，只要英文模式下出现汉字就报错（`O_X HUB` 除外）。
- 语言切换走的是"卸载 + 重建"，所以**任何新的全局状态都要放进 `boot(lang)`**；只有语言包、配色、工具函数、资源缓存可以留在外面。
